LLM URL Prompt

Paste your prompt exactly as you want it delivered — line breaks and indentation included.

 

Why not just paste into the address bar?
  • A URL cannot legally contain a line break, so browsers flatten one you type or paste into the address bar into a space before the page is even loaded. The line breaks are gone before the extension runs.
  • This page encodes the prompt for you, so %0A and %2B are handled correctly.
  • Building a link by hand still works — just encode line breaks as %0A and any literal + as %2B.
  • If a prompt still arrives on one line, tick Debug above. The console then logs the composer's rendered HTML, which shows whether the site or its editor is folding the line breaks.
